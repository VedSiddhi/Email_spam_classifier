How the system works

The system processes your message through multiple machine learning stages before generating the final prediction.

01

Input Message

The user enters an SMS or text message into the analyzer.

02

TF-IDF

03

Naive Bayes

04

Prediction

Built with Machine Learning

SpamGuard uses a Multinomial Naive Bayes classifier trained on a labeled SMS dataset. Text messages are transformed using TF-IDF vectorization before being passed to the classification model.
